# Stock Portfolio Tracker 📈

## Project Description

The Stock Portfolio Tracker is a Python-based project that helps users calculate their stock investments. Users can select stocks, enter quantities, and view their total investment.

## Features

* Displays available stocks and their prices.
* Allows users to select stocks and enter quantities.
* Calculates the investment for each stock.
* Calculates the total investment.
* Saves portfolio details to a text file.

## Technologies Used

* Python 3

## How to Run the Project

1. Install Python 3.

2. Download or clone this repository.

3. Open the project folder in VS Code.

4. Open the terminal.

5. Run the command:

   ```bash
   py stockportfoliotracker.py
   ```

6. Enter the number of different stocks you want to buy.

7. Enter the stock symbols and quantities when prompted.

8. View your portfolio and total investment.

## Output

The program displays the investment for each stock and the total investment. It also saves the results in a file named `portfolio.txt`.
