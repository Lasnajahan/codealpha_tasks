# Basic Chatbot

## Project Description

This project is a simple rule-based chatbot developed using Python. It interacts with users and provides predefined responses based on their input.

## Features

* Greets users with a welcome message.
* Responds to greetings such as hello, hi, and hey.
* Answers the question "How are you?"
* Says goodbye when the user enters bye or goodbye.
* Handles unknown messages with a default response.

## Technologies Used

* Python 3
* Functions
* If-elif-else statements
* While loop
* Input and output

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `py chatbot.py`.
5. Enter a message and interact with the chatbot.

## Learning Outcomes

* Understanding Python functions.
* Using conditional statements.
* Taking user input and displaying responses.
* Creating a simple rule-based chatbot.
