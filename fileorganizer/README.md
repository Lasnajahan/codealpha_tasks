# JPG File Organizer

## Project Description

This project is a Python automation script that moves all JPG images from a selected folder into a new folder named `JPG_Images`.

## Features

* Finds JPG images in a folder.
* Automatically creates a destination folder.
* Moves JPG images to the destination folder.
* Displays the number of files moved.

## Technologies Used

* Python 3
* os module
* shutil module

## How to Run

1. Open the project folder in VS Code.

2. Open the terminal.

3. Run the following command:

   ```bash
   py fileorganizer.py
   ```

4. Enter the folder path containing JPG images.

5. Check the `JPG_Images` folder for the moved images.

## Example

If the source folder contains three JPG images, the program moves them into the `JPG_Images` folder.

## Learning Outcomes

* Creating folders using the os module.
* Moving files using the shutil module.
* Automating repetitive tasks.
