# Hangman Game 🎮

## Project Description

Hangman is a simple word-guessing game developed using Python. The player must guess a hidden word by entering one letter at a time.

## Features

* Random word selection.
* Letter-by-letter guessing.
* Limited incorrect attempts.
* Displays the guessed letters.
* Shows whether the player wins or loses.

## Technologies Used

* Python 3

## How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   ```bash
   python hangman.py
   ```

## How to Play

1. Run the program.
2. Enter one letter at a time.
3. Guess the hidden word before you run out of attempts.
4. Win by guessing all the letters correctly.
